# 汇芯内容创业管家

袁六伟 · 台州汇芯（公众号/视频号：袁六伟）

面向自媒体人和内容创业者的 macOS 菜单栏内容经营工具。它把多平台粉丝、内容表现、增长趋势和复盘建议放在一个轻量面板里。

## 当前版本

v0.1.8 · 2026-11-13

## 已完成

- macOS 菜单栏常驻与独立窗口
- 总览、内容库、平台总览、内容复盘
- 多平台统一数据结构
- 公众号连接入口
- AppID / AppSecret 使用 macOS 钥匙串保存
- 公众号昨日粉丝与图文数据读取链路
- 公众号官方草稿箱读取链路（账号具备内容管理权限时可用）
- 本机白名单不匹配时，自动通过加密 SSH 隧道调用腾讯云中继
- 连接中心增加各平台官方开发者入口，避免把未完成授权伪装成已接通
- X / Twitter 支持填写官方 User Bearer Token，读取账号粉丝、发帖数量等公开指标
- B 站支持填写官方 Access Key、App Secret 和 OAuth Access Token，按官方 HMAC-SHA256 签名验证授权账号
- 小红书支持填写官方 App ID 和 OAuth Access Token，验证 basic_info 授权账号
- 抖音支持填写官方 OAuth open_id 和 access_token，读取粉丝总量、净增粉丝、近 30 天作品数量、新增作品和新增播放
- 其他平台 CSV 导入入口与导入条数状态
- CSV 指标映射：粉丝、净增、发布量、播放、点赞、评论、分享、收藏
- 顶部“更新”会重新读取已保存在本机钥匙串中的官方连接，不再只是刷新界面时间
- 平台卡片明确标注“演示数据 / CSV 导入 / 官方数据”，避免把不同来源混在一起
- 菜单中可导出带数据来源和更新时间的平台 CSV 报告
- 演示数据用于本地体验

## 数据边界

当前界面中的平台数据默认是演示数据，只有在完成平台授权并成功读取后才应替换为真实数据。公众号统计接口需要认证账号的数据权限；本次腾讯云白名单联调确认当前账号可以读取官方草稿箱和素材数量，但数据统计接口返回 `48001`，因此产品采用“官方草稿箱 + CSV 数据导入”的可用降级路线。小红书当前只接入官方 basic_info 身份验证，视频号仍保留 CSV 导入，不伪造未开放的创作者统计接口。

## 接入架构研究

GitHub 上的同类项目拆解和本产品的落地边界见 [ARCHITECTURE.md](ARCHITECTURE.md)。本产品采用“一个平台一个连接器、官方授权优先、没有官方能力就明确降级”的方式。

公众号官方接口的真实联调记录见 [WECHAT_API_RESEARCH.md](WECHAT_API_RESEARCH.md)。

## 其他平台的官方接入准备

- X / Twitter：在 X Developer 创建应用，申请用户读取权限，取得 User Bearer Token 后，在连接中心填写用户名和 Token；应用会读取公开账号指标。X 官方要求通过开发者应用和 OAuth 授权访问账号数据。
- 抖音：在抖音开放平台创建并审核应用，再申请用户视频/数据权限；官方接口需要 OAuth 授权后的 `access_token` 和 `open_id`，不能只凭抖音账号密码读取。
- B 站：先完成开放平台身份认证并创建应用，再取得 `client_id`、`app_secret` 和 OAuth `access_token`。B 站开放接口要求按官方签名协议请求，普通网页接口不作为本产品的数据来源。
- 小红书：先完成开放平台主体与应用审核；在官方能力明确覆盖账号数据前，产品保留 CSV 导入，不接第三方抓取。

## 本地运行

```bash
./build.sh
open "dist/汇芯内容创业管家.app"
```

如需把应用输出到其他目录，可临时设置 `HUIXIN_APP_OUT`，例如：

```bash
HUIXIN_APP_OUT="/你的交付目录/汇芯内容创业管家.app" ./build.sh
```

要求：Apple 芯片 Mac、macOS 14 或更高版本。

## 公众号连接前提

需要公众号管理员提供 AppID 和 AppSecret，并在公众号相关开发者设置中配置本机或服务端出口 IP 白名单。凭证只保存在本机钥匙串，不应提交到 Git 仓库。内容库页面的“刷新公众号草稿”使用官方 `draft/batchget` 接口；如果本机不在白名单内，应用会自动通过 SSH 隧道连接到已加入白名单的腾讯云中继。当前中继服务文件见 `server/wechat-relay.mjs`，只监听服务器本机，不开放公网接口。

## 诚实边界

本项目不绕过平台登录、不抓取受保护页面、不把演示数据标成真实数据。平台未开放的指标，使用者可以选择手动导入或等待官方授权能力。
