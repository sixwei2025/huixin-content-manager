# 汇芯内容创业管家

袁六伟 · 台州汇芯（公众号/视频号：袁六伟）

面向自媒体人和内容创业者的 macOS 菜单栏内容经营工具。它把多平台粉丝、内容表现、增长趋势和复盘建议放在一个轻量面板里。

## 当前版本

v0.1.0 · 2026-11-13

## 已完成

- macOS 菜单栏常驻与独立窗口
- 总览、内容库、平台总览、内容复盘
- 多平台统一数据结构
- 公众号连接入口
- AppID / AppSecret 使用 macOS 钥匙串保存
- 公众号昨日粉丝与图文数据读取链路
- 演示数据用于本地体验

## 数据边界

当前界面中的平台数据默认是演示数据，只有在完成平台授权并成功读取后才应替换为真实数据。小红书和视频号暂不伪造官方接口，后续可增加官方授权或 CSV 导入。

## 本地运行

```bash
./build.sh
open "../outputs/汇芯内容创业管家.app"
```

要求：Apple 芯片 Mac、macOS 14 或更高版本。

## 公众号连接前提

需要公众号管理员提供 AppID 和 AppSecret，并在公众号相关开发者设置中配置本机或服务端出口 IP 白名单。凭证只保存在本机钥匙串，不应提交到 Git 仓库。

## 诚实边界

本项目不绕过平台登录、不抓取受保护页面、不把演示数据标成真实数据。平台未开放的指标，使用者可以选择手动导入或等待官方授权能力。
